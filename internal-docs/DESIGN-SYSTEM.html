03 — Signature move

The giant bold header

This is the single most recognizable device on the site: every top-level page (Careers, Contact, Insights, News) opens with one word or short phrase blown up to 140–200px, uppercase, jammed tight with negative letter-spacing, and centered. It's the loudest element on the page — everything else stays quiet by comparison.

07 — Applying it elsewhere

Rules to carry over

One giant word per page

Every top-level page gets exactly one hero headline at 140–200px, uppercase, Inter 800/900, tight negative tracking. Don't repeat the treatment mid-page — it only works because it's rare.

Eyebrow + title + bar for sub-sections

Below the hero, use the smaller three-part pattern: navy uppercase eyebrow → navy title with one blue-highlighted phrase → 56×4px navy-to-teal gradient bar.

Mono for meta, serif for description

Job/listing cards pair a monospace meta line (location, date, tags) with Source Serif body copy — the contrast between technical label and editorial description is deliberate.

Teal underline = "you are here"

The only nav state change is a 2px teal underline plus bold weight. No background pills, no color swaps.

Two CTA styles, not more

Solid blue pill for inline actions ("View role"), teal-to-blue gradient pill for the one primary conversion action per page ("Talk to expert", "Submit").

Product colors stay local

The purple/pink/teal/orange accent set is scoped to product icon tiles and dropdown hovers only — it never becomes a page background or a heading color.
